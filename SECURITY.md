# Security Policy

## Scope

This repository contains a Claude Skill, documentation, Python helper scripts, and Manim examples.

## Supported versions

The latest `main` branch is supported.

## Reporting a security issue

Open a private report if available, or contact the repository owner.

## Security expectations

This project should not:

- run untrusted shell commands without explanation,
- download arbitrary remote code,
- hide generated files,
- collect secrets,
- require private credentials,
- store user data.

## Safe use

Run generated Manim projects inside a normal development environment or virtual environment.

Before running unfamiliar scripts, inspect them.
