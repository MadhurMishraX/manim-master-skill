# Manim Review Checklist

## Correctness

- [ ] The core concept is accurate.
- [ ] Notation is consistent.
- [ ] No formula transformation changes meaning incorrectly.
- [ ] Edge cases or assumptions are stated when needed.

## Visual clarity

- [ ] Every frame has one main focus.
- [ ] Text is readable.
- [ ] Formulas are not too small.
- [ ] Objects do not overlap.
- [ ] Important elements are highlighted.
- [ ] Colors have consistent meaning.

## Animation quality

- [ ] Motion explains the idea.
- [ ] Timing is not too fast.
- [ ] Waits are used after important moments.
- [ ] Scene transitions feel intentional.
- [ ] Camera movement improves understanding.

## Technical quality

- [ ] All scenes render.
- [ ] `concat.txt` uses correct paths.
- [ ] `final.mp4` exists.
- [ ] Subcaptions exist where narration is implied.
- [ ] High-quality render was done only after low-quality approval.

## Final polish

- [ ] Final frame has one clear takeaway.
- [ ] No debug objects remain.
- [ ] No placeholder text remains.
- [ ] File names are clean.
