# Colors

## Use color as meaning

Example palette:

```python
BACKGROUND = "#0B1020"
PRIMARY = BLUE_B
SECONDARY = GREEN_B
ACCENT = YELLOW
WARNING = RED_B
TEXT_COLOR = WHITE
```

## Consistency

If `x` is yellow once, keep it yellow throughout the scene.

## Contrast

Use high contrast between text and background.

## Avoid

- random colors,
- too many saturated colors,
- red unless something is wrong or important,
- low contrast labels.
