# Design Principles

## Animation is controlled attention

Every frame should answer:

```txt
Where should the viewer look?
Why should they look there?
What changed from the previous frame?
```

## One idea per moment

Do not show five new objects at once.

Bad:

```txt
title + graph + equation + labels + arrows + explanation paragraph
```

Good:

```txt
first the object, then the label, then the equation, then the connection
```

## Symbols must attach to meaning

When a formula appears, connect it to a visual object.

Example:

```txt
x on the axis should match x in the equation.
A vector arrow should match its coordinate representation.
A highlighted term should match the highlighted geometric part.
```

## Color is meaning

Use color consistently.

Example:

```txt
Blue = main object
Yellow = key insight
Green = result
Red = warning or contradiction
```

## Motion must explain

Motion should show:

- transformation,
- causality,
- grouping,
- comparison,
- emergence.

Avoid motion that only exists to look busy.

## Final frame matters

The final frame should be clean enough to screenshot.

It should usually contain:

- one central visual,
- one key formula,
- one short takeaway.
