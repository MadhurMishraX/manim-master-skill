# Code of Conduct

This project is for building a useful open-source educational tool.

## Expected behavior

- Be respectful.
- Give constructive feedback.
- Help beginners learn.
- Keep discussions technical and welcoming.
- Assume good intent, but fix harmful patterns when they appear.

## Unacceptable behavior

- Harassment
- Personal attacks
- Spam
- Doxxing
- Threats
- Deliberately disruptive behavior
- Repeated low-effort or off-topic comments

## Reporting

Open an issue or contact the repository owner.

## Enforcement

Maintainers may edit, hide, or remove content that harms the project or community.
